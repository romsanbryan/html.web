Aquelo

. github

Consistia en un sistema de riego automatizado y controlado por arduino mediante una PWA basada en PHP. En la web se podría ver datos de los cultivos, como la temperatura y la humedad tanto en el aire como en la tierra y mediante un botón activar/desactivar el sistema de riego.

Todos los parámetros se guardaba en una base de datos relacional para tenerlo registrado. Tanto la temperatura como la humedad se registraban cada hora mientras que la activación de riego se registraba al finalizar, guardando tanto la fecha como el tiempo activo.

Tecnologías principales: PHP, SQL Boostrap, JavaScript, wordpress e Ionic
